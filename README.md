# Gurtej "Sunny" Bamrah

Builder and board-certified pharmacist (PharmD, BCPS) in Plainfield, Illinois.

I build software tools by directing AI coding assistants. I set the product vision, write the requirements, choose clinical rules from approved sources, make the design calls and test the results.

Seventeen years in hospital pharmacy shape how I build. In my clinical tools, the dose math is fixed code and each number links to its source. One test showed why: an AI read a dosing protocol, kept each number right, and still left out whole rows and a warning. Since then I do not let AI pull clinical rules from a document on its own.
